# Eman Abdulrauf's Personal Website

A simple personal portfolio site built with plain HTML and CSS. It introduces me, shows what I am working on, and tells people how to reach me.

Live site: https://ema-rauf.github.io/my-portfolio/

## About the project

I am a student learning programming and PCB design. I made this site as my first web project for Hack Club. I wanted to learn how a webpage is structured and styled without using any frameworks or templates, so everything here is written by hand.

## Features

- Navigation bar at the top that jumps to each section
- Hero section with a short intro and a button that links to my projects
- About section with a short introduction
- Projects section with cards that highlight when you hover over them
- Contact section with a link to my GitHub
- Dark theme with a single bright accent color
- Responsive layout that works on phones and desktops

## Built with

- HTML5
- CSS3 (custom styles, Flexbox, hover effects)
- GitHub Pages for hosting

## How to run it locally

1. Clone the repository:
```bash
   git clone https://github.com/ema-rauf/my-portfolio.git
```
2. Go into the folder:
```bash
   cd my-portfolio
```
3. Open `index.html` in your browser. On Linux you can run:
```bash
   xdg-open index.html
```

There is nothing to install and no build step.
